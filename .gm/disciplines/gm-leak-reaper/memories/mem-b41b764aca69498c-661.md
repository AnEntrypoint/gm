gm-mcp bin/ must be built from the committed tree, not the shared work tree -- C:/dev/gm/gm-mcp's work tree carries other lanes' uncommitted src, so `npm run build` there produces a bundle that does not match the committed sources and `npm run verify-build` (check-bin-drift) reddens on all four CI platforms. Working route: `gh api repos/AnEntrypoint/gm-mcp/tarball/<sha>` into a temp dir, `cmd //c mklink /J node_modules C:\dev\gm\gm-mcp\node_modules`, run `node scripts/build.mjs` there, verify with check-bin-drift, then publish that bin. Remove the junction with `cmd //c rmdir` before deleting the temp tree, or rm -rf recurses into the real node_modules.
