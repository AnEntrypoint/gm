POSIX orphanhood is a re-parent to init, not a dead parent pid -- A detached child whose parent exits is RE-PARENTED to pid 1 on Linux/macOS, so its ppid is alive. A 'parent pid is dead' orphan test therefore finds orphans on Windows and finds NONE at all on POSIX -- gm-mcp's leak reaper failed on ubuntu/macos CI and passed on windows for exactly this reason until the predicate became 'parent gone OR parent is pid 1/2 (non-win32)'. Any orphan/leak detector must branch per platform here.
