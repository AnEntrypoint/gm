a heartbeat proves a writer is running, not that the thing it leases exists -- spoint's browser-lease holderIsLive() checked only holder-pid liveness + heartbeat age, so a lease whose browser died heartbeated forever, never hit its TTL, and blocked every GPU lane for four hours. Fixed by requiring the leased browser to exist (dead browserPid, or a DevTools port nothing listens on) regardless of heartbeat. gm-mcp's leak reaper reaps lease records on the same positive-evidence-of-death rule. Note claim() used to killTree the previous holder: now it only kills a holder that is itself dead -- taking a leaked lease is right, killing its lane is not.
