project/plugkit-isolated-local-dispatch-recipe: to witness a rebuilt plugkit without touching live daemons, copy ~/.agentplug/plugins/{bert,libsql,treesitter}.wasm (+.version/.sha256) into a private AGENTPLUG_HOME/plugins, drop the built rs_plugkit.wasm in as gm.wasm, copy ~/.gm-tools/agentplug-runner.exe, and run `AGENTPLUG_HOME=<home> AGENTPLUG_NO_DAEMON=1 CLAUDE_PROJECT_DIR=<clone> runner.exe dispatch gm <verb> '<json body>'` from inside a `git clone --local` of the target project (copy its ignored .gm/gm.db and .agentplug-kv for realistic recall/dual state). AGENTPLUG_NO_DAEMON forces NeverClaimedRunLocally. The Claude scratchpad dir is shared by sibling agents: use a uniquely named subdir, never a generic one like aphome/. Cold first literal scan of spoint (2400 files) costs ~37s of host reads, warm ~3s per fresh process.
