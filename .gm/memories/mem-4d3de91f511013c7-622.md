Lock-order rule for agentplug-host registry: never hold the process-wide SHARED_PLUGINS map lock while taking a pool slot lock. The heartbeat writer held the map lock and blocked on a busy slot (slot_content_hashes used a blocking lock) while the dispatch thread holding that slot needed the map lock for a lazy sibling lookup; the daemon wedged with every thread in futex_wait, diagnosed with gdb thread apply all bt on the stripped binary (the dispatch thread sat in JIT frames under a host import). Read slot hashes with try_lock plus a last-observed mirror, and clone the pool Arc out of the map before touching slots.
