Spool in-file writes must be atomic (write a dot-prefixed temp file in the verb dir, then rename to <N>.txt): the daemon claims a file the moment it appears in in/<verb>/, and a non-atomic write can be claimed before its bytes land, which the guest reports as 'empty memorize body' or an empty dispatch. Witnessed: two of five memorize-fire bodies written directly in one batch arrived empty; the rewritten atomic batch all landed.
