User does not use npm anywhere in the gm/agentplug ecosystem (gm, agentplug, rs-plugkit, or sibling plugin repos) -- never wire an npm-mirror publish step, npm_package_name field, npm registry check, or npm-based install path for any of these repos, even when copying an existing release-workflow template that already has npm wiring for another plugin. GitHub Releases (the release_repo/*-bin pattern) is the sole distribution channel. If an existing repo already carries npm wiring from before this preference was known, that is flagged as debt, never extended to new repos.
