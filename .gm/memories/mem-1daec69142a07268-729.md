agentplug-runner memory: wasmtime Module::from_file with the engine Cache copies the compiled artifact into anonymous memory and backs each data-segment image with a memfd (bert: 135MB code copy plus a 131MB memfd, treesitter 57MB). Module::deserialize_file maps the precompiled .cwasm file instead, so code and images are clean file-backed pages the kernel can drop; the runner keeps those artifacts in ~/.agentplug/precompiled keyed by wasm sha256 and engine compatibility hash. Measured on one project after one instruction: 897MB RSS (753MB anon) before, 409MB RSS (246MB anon) after, and a 118MB boot baseline with all modules loaded. glibc keeps the one-time precompile buffers unless malloc_trim(0) runs after the compile.
