gm history-rewrite/force-push ancestry safety rule: any history rewrite or force-push sourced from an external clone/mirror verifies that source's ancestry against live HEAD first. `git merge-base --is-ancestor <source-tip> <live-HEAD>` must exit 0 before filter-repo/force-push runs against that clone -- a freshly-named clone directory is not proof of freshness, staleness is a content property, not a naming one. Skipping this check risks silently discarding real commits on the remote if the clone turns out stale or wrong-branch.
