Shared plugin pool contract in agentplug-host: any code that evicts a Store (ceiling, pressure release, poisoned dispatch, version swap) must assume a waiter is already queued on that slot, so every acquire site goes through acquire_filled_slot, which refills the slot via ensure_sibling_loaded and retries instead of handing back None. Adversarial review found that host_plugin_call stalled 60s then failed and host_vec_embed failed all three retries when an eviction landed between a waiter taking its ticket and being served. Pair every new eviction path with the refill path, and witness it by forcing a low ceiling (bert at 128 MB evicts on every embed) and dispatching concurrent embeds.
