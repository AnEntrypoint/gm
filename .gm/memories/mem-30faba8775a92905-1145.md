Every subagent prompt dispatching work into one of these submodules must include, as an explicit final step: after pushing the submodule's own commit, cd back to gm's root, git add <submodule-path>, and commit+push gm's own updated pointer in the SAME turn -- never leave that as an implicit "someone will notice."
