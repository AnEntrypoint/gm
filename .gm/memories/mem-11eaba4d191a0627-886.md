agentplug-runner (AnEntrypoint/agentplug, published to agentplug-bin) is a native wasmtime binary loading gm.wasm alongside bert/libsql/treesitter plugins, routing gm.wasm's host_plugin_call/host_vec_embed to them. browser verb = oxibrowser (pure-Rust headless); cdp verb = real Chrome over CDP for screenshots/layout/multi-tab. Launcher install path ~/.gm-tools differs from runner runtime state ~/.agentplug -- check ~/.agentplug/plugins/gm.version for what is served. install.sh/install.ps1 hard-require agentplug-runner, no JS-host fallback. agentplug-runner self-updates wasm and its own exe via two 600s polls; staged .new runner swaps in via self-triggered handoff on next idle tick, no restart needed. Mid-handoff dispatch returns dispatch_orphaned -- bare re-dispatch fixes it. .status.json exposes runner_update_in_progress, last_completed_runner_swap, loaded_plugin_versions.
