gm plugin deploy path for live-witnessing a plugkit change: the loaded gm plugin is ~/.agentplug/plugins/gm.wasm (the SLIM build, install_dir() = ~/.agentplug unless AGENTPLUG_HOME), NOT ~/.gm-tools/plugkit.wasm, which is a legacy artifact the current runner never loads -- swapping the latter changes nothing and loaded_plugin_versions.gm stays on the old version, which is the tell. Procedure: cargo build -p rs-plugkit --release --target wasm32-wasip1 --features slim (needs weights/ present: copy bge-small-en-v1.5.safetensors + bge-tokenizer.json from ~/.gm-tools/weights, the non-slim build include_bytes! them), stop agentplug-runner, copy target/wasm32-wasip1/release/rs_plugkit.wasm over gm.wasm keeping a .pre-<change> backup, restart the runner, dispatch. The runner's plugin poll re-fetches the released asset when the local sha diverges under the same version tag, so the swap is a verification window, not a durable install.
