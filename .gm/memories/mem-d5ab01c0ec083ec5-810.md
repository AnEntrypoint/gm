gm-method: WASM plugin sandboxing detail (drained from AGENTS.md). host_state.rs's WasiCtxBuilder grants no network/env/args inheritance and preopens only the project's own cwd, so WASI-level syscalls cannot reach outside it. Every filesystem env import (host_fs_read/host_fs_write) additionally gates through imports.rs's sandboxed_guest_path, a lexical-normalization boundary check that refuses any path escaping the project root even via ../ traversal -- live-verified: a real path-traversal dispatch against the production binary was refused outright, not silently truncated. Network access exists only through one explicit host_fetch import, never a raw socket. A plugin's entire capability surface is exactly the set of env functions the host chose to register, nothing ambient. Cordis paper Section 6.3.
