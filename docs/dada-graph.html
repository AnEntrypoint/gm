The DADA graph uses the same node layout as the gm graph. A principle is one discipline from a named book or author, a tension stays open until it is resolved, gates guard the edges they sit on, and terminals mark the end nodes. Each edge is forward or a back-reference, and most edges carry a condition.

Every node below is its own anchor, listed flat and in full: 366 nodes, none of them behind a bucket. Each one names every node it reaches and every node that reaches it, in both directions, so a walk can start anywhere and move node to node. The concern index above the list is provenance, not a gate: it says where each book came from and points at the same anchors.
