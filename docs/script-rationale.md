# Script and CI rationale

Moved out of AGENTS.md to keep under 30,000 bytes. Owner: repo root. Each entry names script or workflow it explains.


- `scripts/triage/check-pins.sh`: unpublished pin breaks every fresh recursive clone. Fetches pinned sha into throwaway bare repo.
- `scripts/remote-cmp.mjs`: raw paths once produced `/contents/C:/...` 404s read as "absent". 401 and 403 = auth or rate limit, never absence.
- `scripts/build-graph-page.mjs`: page numbers from graph JSON. Broken edge refuses page before any file written.
- `scripts/sweep-config-sync-litter.mjs`: deleting orphaned state = cache miss, not data loss. `--max-age-days` opt-in.
- `gm-mcp/.github/workflows/verify.yml` (workflow name `build-verify`): name must keep "build". `bump-pins` holds submodule pin while release, publish, build or wasm run non-green. Renaming workflow silently releases hold.
- `.github/workflows/house-clean.yml` keeps only latest release per `-bin` repo. Installers read only that; superseded releases have no reader.
- gm-mcp bundle drift: running gm-mcp snapshots bundle it booted from, reloads only to provably newer bundle. Handover passes listening socket over IPC so port never closed.
- Reaper: child-ledger attribution is safety gate. Process retired only when every predicate measured true (null = unknown). Browser leases retire only on positive evidence of death, not heartbeat. Runner, http server, supervisor detached on purpose, never candidates.
- `gm-mcp/src/ports.js`: probes answer null when unmeasured, never false. Only "nothing listening" licenses retiring port.
- Tool aliases (`rs-plugkit/crates/plugkit-core/src/wasm_dispatch/verbs/git.rs`): `git_reset` takes `ref` or `rev`, and `mode` or `hard`; each pair refused together as `conflicting_fields`. `git_revert` takes `paths` or `ref`. Boolean fields in `gm-mcp/src/verb-table.js` use `booleanLike` (boolean or string), not strict `z.boolean()`.
- Install bundle host: unreachable bundle host warns, keeps deployed bundle (`install.sh`, `bin/gm-install.js`). Never aborts install that already has one.
- `scripts/sweep-config-sync-litter.mjs`: usage `node scripts/sweep-config-sync-litter.mjs [--root <dir>]... [--temp] [--max-age-days N] [--apply]`. Default: only orphaned state (checkout gone) swept. `--max-age-days N` also sweeps older state while checkout survives: cache miss, next sync loses debounce and backoff. Without `--apply` only reports; exit 0 always, sweep never a gate. Deleting one = cache miss, not data loss: "already at tip" test reads `git rev-parse HEAD` in checkout, never stored sha. Never touches checkout dir, `.lock` directory (single-flight mutex), `.staging*` or `.retired`. Nothing in rs-plugkit deletes this state: `config_sync.rs` removes only `.tmp` files.
- `scripts/check-doc-counts.mjs`: usage `check-doc-counts.mjs [root]`. Every count claim in site and docs must equal count of state machine (`gm-config/fsm/graph.json`) or hop graph (`skills/dream-rsi/gm-graph.json`). Exit 1 on claim matching neither. Prints RESULT: PASS otherwise.
- `scripts/check-doc-paths.mjs`: usage `check-doc-paths.mjs [root]`. Every repo path site and docs name must resolve on disk; exit 1 on missing. Bare file name (specify.md, state.md) not checked: names served stage, runtime file or prose key. Paths under uninitialised submodule counted as skipped.
- `scripts/check-graph-traversal.mjs`: usage `check-graph-traversal.mjs [root]`. Checks every node reachable, no non-terminal node dead end in either graph. State machine terminal reachable with COMPLETE edge to it. Hop convergence terminal and halt nodes terminal. Shared nodes agree on kind. Exit 1 on failure.
- `scripts/sync-prose.mjs`: `skills/gm/prose` is source; `gm-config/prose` generated. Edit skill, then run script.
- `scripts/triage/doctor.sh`: usage `doctor.sh` (run from gm root). Exit 1 if watcher dead or pin unpublished. Repo RED only when newest run of workflow on main failed. Older failure that later run fixed not reported.
- `scripts/triage/runner-status.sh`: `.status.json` written by one process, can outlive it. Daemon serving dispatches while status pid gone leaves stale status file. Response written in last 5 minutes proves live runner: not dead watcher, second must not start.
- `notify-gm.yml` in each submodule's `.github/workflows/` (present in every submodule; first in gm-config): on push to main sends `submodule-released` to AnEntrypoint/gm with `PUBLISHER_TOKEN`, so bump-pins runs within seconds not at next cron tick. Exits 1 when token unset, so missing secret shows as red run.
- `gm-config/scripts/witness-parallel-slots-decline.mjs`: witnesses that "Parallel slots (standing rules)" section of `prose/entry.md` carries declined-successor obligation. Usage: `[path-to-entry.md]`.
- `gm-config/scripts/witness-refill-trigger.mjs`: witnesses that section names host completion notice as refill trigger, records measured wait-fallback distribution, and instructions code emits launch list not count. Usage: `[path-to-entry.md] [path-to-instructions-mod.rs]`.
