Rust crates behind gm

The orchestrator, search ranking, code structure parsing and the native host behind gm.
tl;dr
gm = skill for coding agents. MCP server (tool interface agents call) sends each call to native runner. Inside gm walk (one run of state machine), gate reject transition while its check fail. Page list four Rust repos in gm source tree and what each own. To install gm, start with the distribution page.

Runner location and build info

The installer downloads a platform release asset and saves it as ~/.gm-tools/agentplug-runner (on Windows, ~/.gm-tools/agentplug-runner.exe). The asset name has a platform suffix, such as agentplug-runner-linux-x64. Run ~/.gm-tools/agentplug-runner --build-info to see the runner build.

The crates

rs-plugkit

the orchestrator AnEntrypoint/rs-plugkit

Job: runs gm's workflow state machine and its gates, and answers the verbs (named commands) an agent sends it: workflow verbs (instruction, transition, prd-*, unknown-*) and host verbs (fs_*, exec_js, fetch, the git verbs, and memory). The full list is in skills/gm/docs/verbs.md. Its only crate is plugkit-core. Its release build targets wasm32-wasip1 and publishes the WebAssembly module as plugkit-slim.wasm, the build with no baked-in embedding weights.

It enforces a workflow graph of 146 states joined by 376 edges, with 26 gate predicates. The enforced copy at rs-plugkit/crates/plugkit-core/src/orchestrator/lean_graph.json has the same counts as the authored graph, gm-config/fsm/graph.json.

rs-search

the search fusion library AnEntrypoint/rs-search

Job: a dependency-free Rust library for search ranking. Its fusion module merges ranked lists with Reciprocal Rank Fusion, and its tokenize module splits text into identifier-aware tokens. rs-plugkit depends on it for code search ranking. It has no CLI and no server.

rs-codeinsight

the code structure parser AnEntrypoint/rs-codeinsight

Job: a standalone code structure analyzer built on tree-sitter, shipped as a codeinsight command and a library. The release workflow publishes the codeinsight binary to AnEntrypoint/agentplug-codeinsight-bin, and agentplug-runner fetches that plugin binary from there. rs-plugkit answers callers (who calls a symbol) and impact (a walk of the symbol graph from a symbol) queries itself, without linking this crate.

agentplug

the native host AnEntrypoint/agentplug

Job: agentplug-runner is the native host that loads plugkit-slim.wasm and serves the spool, the directory of request and response files that gm writes and polls. Its commands include spool, daemon, dispatch, takeover and plugin. One install directory runs at most one daemon, and that daemon serves every registered project. Its crates are agentplug-host, agentplug-runner.

How a change ships

A change to the gm skill publishes through .github/workflows/skill-release.yml when it lands on main. In rs-plugkit, release.yml calls the reusable workflow wasm-plugin-release.yml, which publishes the WebAssembly module as plugkit-slim.wasm.

Retired repositories

This section lists two retired repositories, rs-exec and rs-learn. It does not list the other retired repositories. Both repositories are archived. The README of each one names rs-plugkit as its replacement.
